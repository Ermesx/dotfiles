# Conventions

## Line endings and formatting

`.editorconfig` is the authority; `.gitattributes` matches it.

- `*.ps1`, `*.ps1.tmpl`, `*.psm1`, `*.psd1`, `*.bat`, `*.cmd`: **CRLF**.
- Everything else (`*.md`, `*.yaml`, `*.json`, other `*.tmpl`): **LF**.
- Indent and other formatting rules: follow `.editorconfig`.

## Scripts

- Scripts must be idempotent: guard every install by checking the target state (existing scripts show the pattern),
  not the presence of the tool. Skip the guard only when the command converges by itself in a `run_onchange` script
  (`dsc config set`).
- User-facing progress lines use `Write-Host "► <Action>" -ForegroundColor Cyan`.

## Generated documentation

Text between `<!-- BEGIN:packages -->` / `<!-- END:packages -->` in `ReadMe.md` and between
`<!-- BEGIN:bindings -->` / `<!-- END:bindings -->` in `docs/terminal-bindings.md` is generated by the `docs-sync`
agent and overwritten on its next run. Change the source (`packages.yaml`, `home/dot_profile/*.ps1`) or the agent
prompt instead of editing the region. After a Claude Code edit of a source file a hook asks the session to run the
agent; for edits made elsewhere (editor, another tool), run it yourself.

## PowerShell profile

The profile imports every module from `packages.windows.modules`, then dot-sources every `~/.profile/*.ps1` by glob
at apply time. A new fragment in `home/dot_profile/` needs no profile edit.
